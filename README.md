### about

B.Tech in Electrical & Electronics Engineering at RGPV, graduating May 2026. Currently a software development intern at Marching Ants Technologies, where I work across a full SaaS stack — React/Next.js on web, React Native on mobile, and PHP/MySQL on the backend. My main contribution there has been a role-based access control system that spans all three layers, from the UI down to the database.

Outside the internship, my focus is Java backend engineering — I care most about the parts of a system that don't show up in a demo: concurrency, data pipelines, and how a service behaves under load rather than just what it returns on a happy path.

- Building backend-heavy portfolio projects (log pipelines, alerting engines) to go deep on concurrency and distributed systems
- Comfortable across the request lifecycle: REST API design, service-layer logic, persistence, and authentication/authorization
- DSA with Java certified (Apna College)
- Open to fresher SDE / backend engineering roles

**<a href="https://github.com/Khwaish0512/log-aggregator">log-aggregator</a>**
<br/>
<sub>status: shipped · java, spring boot, kafka, mysql, docker</sub>

A decoupled log ingestion pipeline built with Spring Boot and Kafka, load-tested from 533 to 2,842 requests/sec. In-memory buffering with scheduled batch flushing handles up to 1,537 logs per JDBC batch insert, paired with a real-time alerting engine using `ConcurrentHashMap` and a sliding-window algorithm. Ships its own multithreaded Java load-testing tool simulating 500 concurrent clients.
